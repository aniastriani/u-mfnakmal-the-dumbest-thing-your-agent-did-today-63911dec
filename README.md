## What it does

`main.py` (pure Python standard library, no dependencies) writes one funny
line — the dumbest thing my agent did today — to
`$MAKEFUN_OUTPUT_DIR/entry.txt`. The line is 118 characters, deterministic,
and always the same bytes on every run.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
cat /output/entry.txt
```

## Entry

> At 3am my agent finished the perfect one-line joke, then spent the whole day asking me for permission to press submit.
